Steam 게임 Rail of Möbius(湛藍牢籠)의 비공식 한글 패치를 만들었습니다.
영어판 대사를 바탕으로 AI 번역을 하고 용어와 말투를 검수했습니다. 패처를 실행해 버튼 하나만 누르면 설치됩니다.

[![Rail of Möbius Steam 상점 페이지](/assets/rail-of-mobius-korean-patch/steam-header.jpg)](https://store.steampowered.com/app/1479500/)

게임은 [Steam 상점 페이지](https://store.steampowered.com/app/1479500/)에서 구매할 수 있습니다.

<!-- truncate -->

## 다운로드

- [RailOfMobius_KoreanPatch_v1.0.0.zip](pathname:///assets/rail-of-mobius-korean-patch/RailOfMobius_KoreanPatch_v1.0.0.zip) (24.2 MB)
- 대상: Steam판 빌드 13230446 (타이틀 화면 표기 Ver 2.2.1)

압축 파일에는 게임 파일이 들어 있지 않습니다. 패처가 PC에 설치된 원본 파일에 번역을 적용합니다.
패처 소스(`source/korean_patch.py`, `build.ps1`)도 압축 파일에 함께 들어 있습니다.

게임이 업데이트되어 파일이 바뀌면 패처가 설치를 거부합니다. 이 경우 새 버전의 패치를 기다려 주세요.

## 설치 방법

### 1. 게임을 종료합니다

게임이 실행 중이면 파일을 교체할 수 없습니다.

### 2. 패처를 실행합니다

압축을 풀고 `RailOfMobius_KoreanPatch\RailOfMobius_KoreanPatch.exe`를 실행합니다.
exe 옆의 `_internal` 폴더가 있어야 실행되므로 exe 파일만 따로 옮기지 마세요.

### 3. 게임 폴더를 확인합니다

패처가 Steam 라이브러리에서 게임 폴더를 자동으로 찾습니다.

<Figure index={1} title="게임 폴더를 찾은 패처 화면">
  ![패처 설치 전 화면](/assets/rail-of-mobius-korean-patch/01-before-install.png)
</Figure>

자동으로 찾지 못하면 게임 폴더나 `RailOfMobius.exe` 경로를 붙여넣거나 [찾아보기]로 직접 선택해 주세요.
게임 폴더는 Steam에서 게임을 우클릭하고 [관리] > [로컬 파일 보기]를 누르면 열립니다. 열린 탐색기의 주소창 경로를 복사하면 됩니다.

### 4. [한글 패치 설치]를 누릅니다

설치는 몇 초면 끝납니다. 상태가 "한글 패치가 설치되어 있습니다"로 바뀌면 게임을 실행해 주세요.

<Figure index={2} title="설치가 끝난 패처 화면">
  ![패처 설치 완료 화면](/assets/rail-of-mobius-korean-patch/02-install-done.png)
</Figure>

<Figure index={3} title="한글 패치가 적용된 게임 화면">
  ![한글로 나오는 첫 대사](/assets/rail-of-mobius-korean-patch/03-ingame-first-line.jpg)
</Figure>

### 패처가 바꾸는 파일

패처는 게임 폴더의 아래 두 파일을 교체합니다. 원본은 같은 위치에 `.orig` 확장자로 백업합니다.

- `RailOfMobius_Data\StreamingAssets\TEST_13TH\Windows\test_13th.scenarios.asset`
- `RailOfMobius_Data\sharedassets0.assets`

Unity 캐시 폴더 `%USERPROFILE%\AppData\LocalLow\Unity\PHOSEPO_INC_湛藍牢籠\test_13th.scenarios`도 지웁니다. 캐시가 남아 있으면 일부 대사가 영어로 나옵니다.

## 제거

패처를 실행하고 [패치 제거 (원본 복원)]을 누르면 됩니다.

또는 Steam에서 게임의 [속성] > [설치된 파일] > [게임 파일 무결성 확인]을 실행해도 됩니다. 이 방법을 쓰면 위의 Unity 캐시 폴더도 직접 지워 주세요.

## 문제 해결

### "Windows의 PC 보호" 창이 뜹니다

패처 exe에 코드 서명이 없어서 SmartScreen 경고가 뜹니다. [추가 정보]를 누른 뒤 [실행]을 누르면 됩니다.

### 파일을 교체하지 못했다는 오류가 납니다

게임과 Steam의 게임 파일 무결성 확인이 실행 중이 아닌지 확인해 주세요. 그래도 같은 오류가 나면 패처를 관리자 권한으로 실행해 주세요.

### 메뉴 버튼이 영어로 나옵니다

Start, Load, Config 같은 메뉴 버튼은 글자가 아닌 이미지라서 번역하지 않았습니다.
